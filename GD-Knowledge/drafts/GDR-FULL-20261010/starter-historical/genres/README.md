# Genres

One Markdown file per genre with its own research guidance and conditional application notes belong here after research and review. There are no completed entries in this starter.

See the [taxonomy](../TAXONOMY.md), [index](../INDEX.md) and [shared research instructions](../RESEARCH_INSTRUCTIONS.md). New files must use the matching [template](../templates/genre.md). Do not populate this folder with unsourced encyclopedic summaries merely to fill the taxonomy.
