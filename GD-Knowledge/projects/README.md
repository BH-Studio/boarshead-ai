# BH GDR Project setup

Create or use these exact five workspaces. Each profile below contains a self-contained “Paste into Project instructions” section and an initial chat prompt. Copy only that section into instructions, not the entire document. These are portable research instructions; no new personal custom GPT is required.

2. [BH-GDR-Worlds-and-Characters](worlds-and-characters.md)
3. [BH-GDR-Presentation-and-Interaction](presentation-and-interaction.md)
4. [BH-GDR-Genres](genres.md)

## Initial shared file set

Upload [Research instructions](../RESEARCH_INSTRUCTIONS.md), [Evidence rules](../EVIDENCE_RULES.md), [Taxonomy](../TAXONOMY.md), [Index](../INDEX.md), [Review gates](../REVIEW_GATES.md) and [Registers](../REGISTERS.md). Add this Project's own profile.

Foundations and Worlds also receive [topic](../templates/topic.md) and [pattern](../templates/pattern.md) templates: nine files each.

Presentation receives those two templates plus the [genre template](../templates/genre.md) and [audio pilot](../pilots/audio-tension-and-ambience.md): eleven files.

Genres receives the genre, topic and pattern templates plus the audio pilot: eleven files.

Coordination receives all three templates, the pilot, [Retrieval and distribution](../RETRIEVAL_AND_DISTRIBUTION.md), [Compatibility](../COMPATIBILITY.md) and [Manifest](../MANIFEST.md): fourteen files.

These are recommended starter sets, not a claim that uploads occurred. A deployment may use a carefully labeled Markdown starter pack instead, provided its manifest and entry boundaries remain clear. Keep canonical relative paths recorded when the upload UI flattens names.

## Verify configuration

Confirm the exact Project name, saved instructions, selected files and accessible release version. Run the relevant tests in Review Gates and record results. An initial prompt is provided for a new chat; do not send it if doing so would launch unapproved work. Keep the review-only scope intact.

No Project is assumed to know the conversations or attachments in another. Transfer reviewed work through explicit versioned Markdown handoffs and canonical GitHub updates. Do not promise that connector indexing or Project memory automatically synchronizes a repository.
