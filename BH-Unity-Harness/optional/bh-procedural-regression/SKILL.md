# Optional procedural regression

Read the project's approved overlay, seed/stream ownership, stable-ID and save-version contracts, and applicable acceptance IDs. Use the same reviewed verification bindings as the core. Test fixed seeds, named RNG stream isolation, deterministic ordering, save/load and migration behavior, invalid inputs, nominal/target/stress scales, and relevant generation invariants. Distinguish semantic equality from byte equality and record the intended platform/runtime guarantees.

Inputs must identify real project expectations, not universal assumed seeds or numeric budgets. Missing invariants block planning. Preserve failed artifacts and label synthetic examples. Do not alter vendor content, regenerate persistent data, or invent a second consumer to claim reuse. Return actual mapped evidence and human-only judgments separately.

Installation is optional and separately approved. This directory is deliberately outside project-template/.agents/skills and is not installed by the standard manifest.
