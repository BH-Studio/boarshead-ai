# b1-narrative-contracts

Package: B1-CODEX-OPS | Version: 0.1.0
Authority: use only within the adopted repository instructions and the current authorized task.

## Inputs and authority

Read the actual approved narrative baseline named by the coding package, its relevant complete
sections and status ledger, plus system/session contracts. The bundled opening-arc v1.0 contains
reported approvals, working synthesis and unresolved interfaces; do not treat all prose or sample
dialogue as approved script. M must resolve affected shared-record conflicts before implementation.

## State and authoring

Separate world truth, campaign facts, participant knowledge, dialogue delivery history, contact
availability and explicitly granted permissions. A discovered terminal is not the AGI's physical
location. Presentation labels, debug views and recap eligibility must respect intended knowledge.
Author-level facts are not automatically player-visible. Provide author/debug visibility into
eligibility, prerequisites and fallback without exposing spoilers in the shipped interface.

## Boundaries to verify when the opening arc is the approved input

Preserve player-earned mission causality, reliable mandatory contributions, optional lore/HQ,
equal human participation and the no-punishment narrative rule. Check no AGI role in Mission 1,
minor ambiguous help in Mission 2, first direct contact late Mission 3, remote contact afterward,
and no actionable containment location/access before the stated Missions 6–8 window. Do not
turn that window into a chosen exact rescue mission. Do not invent overseas staging, HQ form,
principles, relationship penalties, dialogue or consent behavior from open recommendations.

## Integration and validation

Verify subtitle/speaker labeling, protected critical beats, shared access to essential information,
retry/replay suppression and recap. For joins/disconnects, use only the approved session model.
Check skips, missing optional clues, repeated objectives and load/retry cannot block main progress,
leak a reveal or manufacture punitive relationship consequences. Session host authority is not
narrative consent. Bots may not become an unapproved authority or spoiler source.

## Output

Return requirement-to-state/event/UI trace, authoring setup, synthetic progression fixtures,
actual validation and open decisions. The fictional intelligence is authored game content unless
a separate human-approved system explicitly requires live AI services; never add API credentials,
network model calls or unscripted story authority by implication.
